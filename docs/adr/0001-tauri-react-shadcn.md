# 1. Tauri 2 + React + shadcn/ui

Status: accepted.

Libreri is a desktop app for macOS, Windows and Linux. Tauri 2 gives a small download (the OS web view instead of a bundled browser) and a Rust core for file-heavy work. The interface is React + TypeScript with shadcn/ui components and Lucide icons (the shadcn.io icon set). Electron was rejected for size; a native toolkit per OS for cost.
